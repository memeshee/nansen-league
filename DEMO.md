# Demo video guide — 90 seconds that win

Target: one continuous screen recording, Telegram on the left, dashboard on
the right, voiceover. No editing needed if you follow the shots. Total ~90s.

## Setup (5 min, do once)

- [ ] Desktop Telegram open, chat with [@righttofight_bot](https://t.me/righttofight_bot), input box empty
- [ ] Dashboard open: https://smart-money-league.fly.dev/ (refresh once, confirm numbers loaded)
- [ ] Recorder: OBS / Loom / phone — 1080p, capture both windows side by side
- [ ] Do Not Disturb on. Close other tabs (never show API keys — nothing secret appears in normal use, but keep `.env` closed anyway)
- [ ] Mic check: one test sentence, peaks at ~70%
- [ ] Pick your demo token NOW: run `/check <mint>` once off-camera. Use it only if it returns a verdict in <10s. Good candidates are high-volume majors (they have the richest Nansen data). Have a backup mint ready.

## Shot list (read timecodes while recording)

**0:00–0:10 — Hook (dashboard fullscreen).**
Say: *"Every trading bot shows you data. This one tells you what to do —
and proves it was right. Nansen data in, Jev verdicts out."*
Point: sweep cursor across conviction donuts → track-record hit rate.

**0:10–0:25 — The league (Telegram: /board).**
Type `/board`, send. Say: *"The game: draft proven smart-money wallets
into weekly rounds, settled on live Nansen PnL — not vibes, wallet
performance."* Point: tap-to-copy `/draft` button as it arrives.

**0:25–0:30 — Draft + scout (Telegram: /draft).**
Paste one wallet from `/board`, send. Say: *"Every pick gets a scout
report — profiler data graded S to C before my points go in."*
Point: the grade line when it lands (~3s).

**0:30–0:55 — THE money shot (Telegram: /deep).**
Type `/deep <your-mint>`, send. Say NOTHING for 3 seconds — let the
"evidence in, judging" messages land. Then: *"Six Nansen endpoints in
parallel — flows, buyers, sellers, holder concentration — into one batched
AI judgment. Conviction, zero to a hundred, in about six seconds, for ten
API credits."* Point: each dimension line as you name it (bullish flow,
accumulation, holder safety, dump risk, action).

**0:55–1:10 — Proof (Telegram: /record, then dashboard).**
Type `/record`, send. Say: *"And it keeps score. Every dossier graded
against what the price actually did next — right here, re-runnable by
anyone."* Switch to dashboard, point: calibration scatter + hit rate.

**1:10–1:25 — Economy + close (dashboard: credit economy).**
Scroll to Credit economy. Say: *"Every call burns credits, so a second AI
stands guard — glance or deep-dive, decided before anything is spent. The
bot rations its own budget and publishes the receipts."* End on hero.
Say: *"Smart Money League — draft proven wallets, get verdicts with teeth.
Links below."* Stop recording.

## Say / don't say

- SAY: "conviction with calibrated confidence", "graded against real prices",
  "ten credits, six seconds", "rations its own budget".
- DON'T SAY: "AI-powered" (empty), "blockchain革命" (it's one chain: Solana),
  "guaranteed returns" (instant disqualification energy), any token as a
  recommendation (say "example", never "buy").
- If a command hangs >15s on camera: smile, say *"live data, live demo"*,
  cut, re-record just that shot. Two takes max per shot.
